# Christie_-Akpan_-week1_ -Finance
Investment Analysis Project

Project Overview

An investment analysis project using Excel, Sql and Power BI to analyze investors' preferences and investment decisions
The analysis provides insights that can help stakeholders better understand investors' needs and make informed decisions.

This project analyzes investors' preferences, investment choices, and the factors influencing their investment decisions. The goal is to identify patterns in investment behaviour based on demographic information, investment objectives, and product ratings.


 Project Objectives

- Analyze investors' preferred investment products.
- Examine investment preferences by gender and age group.
- Identify the major factors influencing investment decisions.
- Understand investors' investment objectives.
- Analyze ratings given to different investment products.
- Provide actionable recommendations to stakeholders based on the findings.

Tools Used

- Microsoft Excel: Data cleaning, data preparation, and preliminary analysis.
- SQL: data query, analysis. 
- Power BI: Data visualization, dashboard development, and reporting.
- GitHub: Project documentation and portfolio management.

 Project Files

The repository contains the following project materials:

- Raw Data: The original dataset before cleaning.
- Cleaned Data: The dataset after correcting inconsistencies and preparing it for analysis.
- Pivot Tables: Summaries used to explore patterns and trends in the data.
- Dashboard: Interactive visualizations presenting key findings.
- Report: A summary of the analysis, findings, and recommendations.

 Key Areas of Analysis

1. Investment preferences by product.
2. Investment preferences by gender and age.
3. Factors influencing investment choices.
4. Investment objectives.
5. Average ratings of investment products.
6. Demographic patterns in investment behaviour.

 Key Insights

The analysis explores differences in investment preferences, the factors that influence investors' decisions, and how investment choices vary across demographic groups.

Specific findings and insights are documented in the project report and presented in the Power BI dashboard.

Recommendations

Based on the findings, stakeholders can use the analysis to:

- Tailor investment products to the preferences of different investor groups.
- Develop targeted investment strategies for specific demographics.
- Improve investment product offerings based on investor ratings and preferences.
- Align investment services with investors' financial objectives.
- Use data-driven insights to support investment planning and decision-making.

 Project Outcome

This project demonstrates the use of Excel and Power BI to transform raw data into meaningful insights. It also highlights how data analytics can support better understanding of customer behaviour and informed business decisions.
